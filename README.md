# Borrowly prototype

Clickable prototype for HCDIx Team 4 (Crowded City): borrow a table, chairs or a TV from neighbors for the night you host.

- Live: https://danielen1337.github.io/borrowly-prototype/
- On a laptop it shows a phone frame with notes; on a phone it runs full-screen.
- iPhone: open the link in Safari, then Share → Add to Home Screen.

`index.html` is the whole app (no build step). `Dockerfile` + `Caddyfile` are for hosting on Railway instead.
